# The Tired Dark Lord: A 100-Word Villain Monologue

A 96-word monologue from a dark lord who has held the same mountain pass
for fifty years — tolls, ravens, a steward, a ledger, a curse — and is
secretly just very tired. The weariness shows in the rhythm and the small
deflections, never in a plain statement of it. The sting lands in the last
line: he has climbed the stairs four thousand times, so this time it is the
hero's turn.

Run: `python3 main.py` (writes /output/entry.txt)
